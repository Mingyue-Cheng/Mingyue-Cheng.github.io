The active iFLYTEK asset is the complete Chinese/English blue logo from the linked Wikimedia Commons record, which credits iFLYTEK and its website as the original source. It is stored unchanged, with a transparent background and no synthetic upscaling or redrawing. The record labels the artwork PD-textlogo and notes that trademark restrictions still apply. Its display width remains 122 CSS pixels, providing approximately 4.5 source pixels per CSS pixel for high-density screens. The new filename prevents a cached low-resolution image from being reused.

The previous `iflytek.png` (122 × 37) is retained as a legacy asset and is no longer referenced by the homepage. It came from a PNG data URI in [official homepage JavaScript](https://www.iflytek.com/cn/static/js/index.18428659f72bb14a55a6.js?6bc0633f4add4c8d3f8c), webpack module 52, imported by footer module 54.
